숏충이 업로더

개인이 직접 만든 자동매매 봇의 매매 기록을 영상으로 만들어, 운영자 본인의 유튜브 채널에 업로드하는 개인용 도구입니다.

무엇을 하는 프로그램인가

바이비트(Bybit) 선물 계좌에서 자동매매 봇이 체결한 내역을 12시간마다 모아 세로형 영상으로 렌더링하고, YouTube Data API v3 를 통해 운영자 본인의 채널에 올립니다. 운영자 한 사람이 자신의 계정으로만 사용합니다.

Google 계정 데이터를 어떻게 쓰나

  • 요청하는 권한은 youtube.upload(영상 업로드)와 youtube.readonly(채널 정보 확인) 두 가지뿐입니다.
  • 발급받은 토큰은 운영자의 개인 컴퓨터에만 저장되며, 외부로 전송하지 않습니다.
  • 영상 업로드 외의 목적으로 사용하지 않고, 누구에게도 제공하거나 판매하지 않습니다.

이 영상은 투자 권유가 아닙니다

공개되는 매매 기록은 실제 계좌의 과거 결과일 뿐이며, 미래 수익을 보장하지 않습니다. 레버리지 거래는 원금 전액 손실이 가능합니다.
