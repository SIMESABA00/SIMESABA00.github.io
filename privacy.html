개인정보처리방침

숏충이 업로더 (Shot Auto Trade) · 최종 수정일 2026년 10월 30일

1. 이 도구의 성격

숏충이 업로더는 개인이 자신의 유튜브 채널에 영상을 올리기 위해 만든 개인용 프로그램입니다. 운영자 본인 외의 사용자를 받지 않으며, 회원가입이나 로그인 기능을 제공하지 않습니다.

2. 수집하는 정보

제3자로부터 어떠한 개인정보도 수집하지 않습니다. 운영자 본인의 Google 계정에 대해 다음 정보에 접근합니다.

  • YouTube 채널 기본 정보 (채널명, 채널 ID, 영상 수) — 업로드 대상 확인 목적
  • 영상 업로드 권한 — 운영자 본인 채널에 영상을 게시하기 위한 목적

3. 요청하는 권한 범위

  • https://www.googleapis.com/auth/youtube.upload — 영상 업로드
  • https://www.googleapis.com/auth/youtube.readonly — 채널 정보 조회

그 외의 권한은 요청하지 않습니다.

4. 정보의 저장과 보관

OAuth 인증 토큰은 운영자의 개인 컴퓨터 안에만 파일로 저장됩니다. 외부 서버로 전송하지 않으며, 별도의 데이터베이스나 클라우드에 보관하지 않습니다. 운영자가 파일을 삭제하거나 Google 계정 설정에서 접근 권한을 철회하면 즉시 폐기됩니다.

5. 정보의 제공 및 공유

Google 계정에서 얻은 어떠한 정보도 제3자에게 제공, 판매, 양도하지 않습니다. 광고 목적으로 사용하지 않으며, 다른 서비스와 연동하지 않습니다.

6. Google API 제한적 사용 요건

이 프로그램의 Google API 사용은 제한적 사용 요건(Limited Use Requirements)을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

7. 권한 철회

운영자는 Google 계정 권한 페이지에서 언제든 이 프로그램의 접근 권한을 철회할 수 있습니다.

English summary

Shot Auto Trade (“숏충이 업로더”) is a personal, single-user tool that uploads videos to the operator’s own YouTube channel. It collects no personal data from any third party. It requests only the youtube.upload and youtube.readonly scopes. OAuth tokens are stored solely on the operator’s local machine and are never transmitted to any server, shared, or sold. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: khsbit79@gmail.com
